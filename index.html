ShopSmart QA Automation Suite

Recorded test runs

A pytest suite covering three surfaces across two targets: desktop and mobile web driven by Playwright against a public practice site (automationexercise.com), plus native iOS driven by Appium / XCUITest against the Sauce Labs demo app on an iPhone Simulator. 11 tests spanning happy-path and negative scenarios, built on page objects and pytest fixtures, headless by default, with pinned dependencies and automatic video recording of every run. Ten unedited recordings from a 2026-07-28 headless run are published, all passing.

The badge is the deterministic gate — dependency install, lint, unit tests and collection integrity, run on every commit against two Python versions. The live web suite runs on a nightly schedule and is reported separately rather than wired to the badge, because a badge pointed at a third-party practice site goes red for reasons the code does not control. Native iOS is excluded from CI by design and run locally.
